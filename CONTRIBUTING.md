# Corrections and contributions

For a date correction include state/territory, year, term, government source URL, access date, and whether it is a student day, staff day or formal term boundary. Include school-specific exceptions only with the school’s own source and clear scope. Preserve conflicts with a note rather than choosing an unsupported answer.

Keep content in Markdown. No JSON, CSV, scripts, workflows, scraped contact lists, private family data or credentials. Cite sources near each affected table and update README and the state page together. Links should help the reader complete a planning task; disclose commercial affiliation and avoid repetitive promotional text.

Check local Markdown references and date transcription without running builds or CI. Publishing and school bookings are separate actions. Do not add scheduled checks or workflows as part of a content correction.
